# 03 — 人设与星座知识库

## 分层模型

```text
element(water)          ← 持续提升主战场
  └─ sign(pisces)       ← 只写差分
       + mbti(INFP)
       + overrides
            ↓ PersonaCompiler
       persona_pack
```

## 首版已发布种子

首版为所有用户人设选择提供完整可用集合：四元素为共性底座，12 星座仅保存相对元素
的差分；16 型 MBTI 保存沟通偏好差分。所有条目均以 `version=1`、`status=published`
写入，后续运营修改必须新增版本并发布，不得直接更新已发布行。

| 元素 | 星座 |
|------|------|
| fire | aries、leo、sagittarius |
| earth | taurus、virgo、capricorn |
| air | gemini、libra、aquarius |
| water | cancer、scorpio、pisces |

MBTI：INTJ、INTP、ENTJ、ENTP、INFJ、INFP、ENFJ、ENFP、ISTJ、ISFJ、ESTJ、ESFJ、ISTP、ISFP、ESTP、ESFP。

## PersonaCompiler

**输入：** published 的 element + sign + mbti + profile.overrides + 可选 daily_context  
**输出：** 见 `xiaozhi-server/docs/03` 的 `persona_pack` JSON  
**要求：** 纯函数可测；结果可缓存（key=`device_id+kb_version+daily_date`）

## 发布与钉扎

1. 运营编辑 draft → 审核 → `status=published`，version++  
2. `follow_latest=true`：下次编译用最新 published  
3. `follow_latest=false`：钉死 `kb_version`  
4. 可按 element/sign 灰度（配置表或环境开关）  

## 持续提升闭环

```text
对话脱敏 → agent-worker 产 kb_feedback_candidates
  → admin 审核合并 → 新 published version
  → 未钉扎设备下次会话生效
```

Agent **不得**直接改 published 行。

## 日运短上下文（P1）

- 表 `persona_daily_context`：按日缓存一句/一小段  
- 来源：规则模板 / 第三方 / LLM 生成（产品待拍板）  
- **不进**实时重算路径
