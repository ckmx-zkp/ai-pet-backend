### 2026-08-01 auth 上线验证（真实 PG 端到端）

- `POST /api/auth/register`（tester01）→ 201 返回用户对象；重复注册 → 409
- `POST /api/auth/login` → 200 + JWT；`GET /api/auth/me`（Bearer）→ 200 用户对象
- 错误密码 与 不存在用户 → 逐字节一致的 401（防用户枚举）
- `audit_logs` 已写入 register/login 各一条

### 2026-08-01 CORS 上线

- 新增 CORSMiddleware，白名单走 `CORS_ORIGINS` 环境变量（默认放本地 Vite 5173）
- 预检验证：OPTIONS `/api/auth/login` + `Origin: http://localhost:5173` → 返回 `access-control-allow-origin/credentials/methods` ✅
- 管理台公网域名确定后，把该域名追加到服务器 `.env` 的 `CORS_ORIGINS` 并 `docker compose up -d web-api`

## 4. 日常运维命令（在服务器上执行）

```bash
cd /opt/ai-pet/ai-pet-backend

# 更新部署（代码 push 后）
git pull && docker compose up -d --build

# 数据库迁移
docker compose run --rm web-api alembic upgrade head

# 看状态 / 日志
docker compose ps
docker compose logs -f web-api        # 或 memory-mcp / agent-worker

# 进入数据库
docker exec -it ai-pet-backend-postgres-1 psql -U postgres -d ai_pet

# 重启单个服务
docker compose restart web-api
```
