## 4. 日常运维命令（在服务器上执行）

```bash
cd /opt/ai-pet/ai-pet-backend

# 更新部署（代码 push 后）
git pull && docker compose up -d --build

# 数据库迁移
docker compose run --rm web-api alembic upgrade head

# 看状态 / 日志
docker compose ps
docker compose logs -f web-api        # 或 memory-mcp / agent-worker

# 进入数据库
docker exec -it ai-pet-backend-postgres-1 psql -U postgres -d ai_pet

# 重启单个服务
docker compose restart web-api
```
