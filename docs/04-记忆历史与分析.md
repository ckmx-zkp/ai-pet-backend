# 04 — 记忆、历史与分析

## 脱敏历史

- 来源：`xiaozhi-server` 旁路 `POST /api/internal/chat/events`
- 只存 `content_redacted`；原始音频默认不落库  
- 查询：按设备 + 时间窗 + limit  
- 删除：按日/按会话物理删或软删，须写 `audit_logs`  

## 记忆

| source | 默认 status |
|--------|-------------|
| manual | active（或直接可用） |
| agent | candidate → 人审后 active |
| import | 按策略 |

- Memory MCP 读写本表（仅 active 可被对话检索，除非工具指定）  
- tags 可含 `element_water` / `horoscope_concern` 等  
- 导出：建议 V0.2 提供「导出我的数据」  

## 分析（agent-worker）

| kind | 说明 |
|------|------|
| `daily_summary` | 日摘要 |
| `emotion_tags` | 文本情绪标签 |
| `memory_suggest` | 记忆候选 |
| `persona_fit_review` | 人设契合观察（供 KB 反馈） |
| `daily_horoscope_note` | 运势小记草稿 |

写入 `analysis_results.payload`；**不阻塞**语音。

## 外设快照

`POST /api/internal/peripheral/events` → 覆盖写 `device_peripheral_state`。

## 验收
