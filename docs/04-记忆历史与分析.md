# 04 — 记忆、历史与分析

## 脱敏历史

- 来源：`xiaozhi-server` 旁路 `POST /api/internal/chat/events`
- 只存 `content_redacted`；原始音频默认不落库  
- 查询：按设备 + 时间窗 + limit  
- 删除：按日/按会话物理删或软删，须写 `audit_logs`  

## 记忆

| source | 默认 status |
|--------|-------------|
| manual | active（或直接可用） |
| agent | candidate → 人审后 active |
| import | 按策略 |

- Memory MCP 读写本表（仅 active 可被对话检索，除非工具指定）  
- tags 可含 `element_water` / `horoscope_concern` 等  
- 导出：建议 V0.2 提供「导出我的数据」  

## 分析（agent-worker）

| kind | 说明 |
|------|------|
| `daily_summary` | 日摘要 |
| `persona_growth` | 人设成长建议 |
| `relationship_update` | 宠物-主人相处关系推断（会话结束 / 记忆变更） |
| `memory_profile` | 已确认记忆画像（E6.1） |
| `data_export` | 用户数据导出快照（E8） |
| `emotion_tags` | 文本情绪标签 |
| `memory_suggest` | 记忆候选 |
| `persona_fit_review` | 人设契合观察（供 KB 反馈） |
| `daily_horoscope_note` | 运势小记草稿 |

写入 `analysis_results.payload`；**不阻塞**语音。

### `memory_profile` payload（E6.1，钉死）

手工新建、编辑、归档，或 candidate 审核通过后入队 `memory_profile`；worker 只读
`status=active` 记忆，产出一张可直接展示的卡片。同一设备若已有 pending 任务则跳过
（幂等）。`GET /devices/{id}/analyses?kind=memory_profile` 取最新一条即可。

```json
{
  "remembered": [
    {"title": "喜欢晚归时有人等", "summary": "主人常加班，希望回家被接住。", "tags": ["care"]}
  ],
  "companion_impact": "开场少催促，先问累不累，再聊正事。",
  "memory_count": 3,
  "updated_from": "create"
}
```

`updated_from` ∈ `create|update|archive|approve`。`remembered` 最多 8 条，不含 candidate、
不含原文级敏感字段。无 active 记忆时仍写一条空画像（`remembered=[]`，`memory_count=0`）。

### `relationship_update` payload

会话结束（`daily_summary`）与记忆变更（`memory_profile`）时，worker 根据脱敏对话 +
`status=active` 记忆 + 当前 `bond` 推断相处关系。先落分析记录，再按阈值回写
`persona_profiles.bond`：首次 ≥0.6，同型刷新 ≥0.5，换型 ≥0.8。`decision=hold` 不改。
用户 `PUT /devices/{id}/relationship` 为 `source=manual`，立刻覆盖。

```json
{
  "kind": "beloved_child",
  "label": "爱子",
  "summary": "主人惯着你，你也黏他",
  "confidence": 0.82,
  "decision": "approve",
  "applied": true,
  "evidence": ["总叫你小家伙", "记得你怕黑"]
}
```

## 导出与保留（E8）

- `POST /devices/{id}/export` 同步打包当前用户可见数据为 JSON（只含脱敏消息与已确认记忆；
  八字只回「已录入」状态，不回生辰原文）。并落一条 `data_export` 分析记录。
- 保留：`chat_messages` 180 天；`daily_summary`/`persona_growth`/`relationship_update`/`data_export` 90 天；
  `memory_profile` 180 天；已完成 `agent_tasks` 30 天。worker 东八区 05:00 后每日扫描清理。
- `GET /admin/ops/metrics` 只读任务计数，不含对话原文。
