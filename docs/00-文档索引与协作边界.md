# 00 — 文档索引与协作边界

## 本仓在体系中的位置

业务**真源**所在：账号、设备资产、星座/MBTI KB、persona、脱敏历史、记忆、分析结果、外设快照、审计。

| 依赖我 | 我依赖 |
|--------|--------|
| `xiaozhi-server` 拉 pack / 旁路写入 / Memory MCP | 外部 LLM API（摘要/编译辅助） |
| `ai-pet-admin` 管理台 API（含 `/admin/*`） | PostgreSQL / Redis /（可选）OSS |
| `ai-pet-app` 用户端 API（手机+桌面，不含 KB 发布） | |
