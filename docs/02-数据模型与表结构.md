# 02 — 数据模型与表结构

> 引擎建议：PostgreSQL。命名可微调，语义勿漂。

## 表清单

| 表名 | 用途 | 首版 |
|------|------|------|
| `users` | 账号 | ✅ |
| `devices` | 设备资产与在线镜像 | ✅ |
| `zodiac_kb_entries` | 星座知识库 element/sign | ✅ |
| `mbti_kb_entries` | MBTI 条目 | ✅ |
| `persona_profiles` | 用户人设与 kb_version | ✅ |
| `chat_sessions` | 会话 | ✅ |
| `chat_messages` | 脱敏消息 | ✅ |
| `memories` | 长期记忆 | ✅ |
| `analysis_results` | 摘要/标签/小记 | ✅ |
| `device_peripheral_state` | 外设快照（一设备一行） | ✅ |
| `audit_logs` | 审计 | ✅ |
| `kb_feedback_candidates` | KB 优化候选 | △ |
| `persona_daily_context` | 日运短上下文 | △ |

**明确不建（首版）：** 家庭成员、社交、媒体库、每条消息 embedding、IP 卡牌权益、重型星历库。

## 关键字段（摘要）

### users
`id, login_name, password_hash, role(user|admin), status, created_at, updated_at`

### devices
`id, user_id(nullable), device_uid(MAC/SN，硬件核心 ID), binding_id(UUID/随机码，app 认领 ID), name, capabilities(jsonb), online_at, firmware_version, created_at`

- `id` 是后端平台管理 ID，仅供内部关系与管理端运维定位；
- `device_uid` 由小智/设备使用，唯一且不作为 app 绑定凭据；
- `binding_id` 由后端在设备首见时生成，唯一、不可猜测，供 app 扫码/输入绑定；
- `user_id` 只记录当前 app 用户归属，admin 不得通过用户绑定接口写入。

### zodiac_kb_entries
`id, level(element|sign|modality), key, parent_key, version, status(draft|published|archived), payload(jsonb), updated_at`

`payload` 建议键：`traits, taboo, style, prompt_fragments, emotion_map, retrieval_hints`

### mbti_kb_entries
`id, key, version, status, payload(jsonb), updated_at`

### persona_profiles
`id, user_id, device_id, sun_sign, mbti, kb_version, follow_latest(bool), overrides(jsonb), compiled_summary(jsonb), updated_at`

### chat_messages
`id, session_id, device_id, role, content_redacted, created_at`  
索引：`(device_id, created_at)`

### memories
`id, device_id, user_id, title, content, status, source(manual|agent|import), tags(text[]), embedding(optional), created_at, updated_at`

### device_peripheral_state
`device_id PK, eye_emotion, eye_gaze, eye_closed, extra(jsonb), updated_at` — **覆盖写**

## 访问路径约束

- 历史默认按 `device_id + time` 短路径，禁止无分页全表扫  
- 向量只挂 `memories`  
- 分析异步写 `analysis_results`  

## 迁移建议

用 migrate 工具（Flyway/Alembic/golang-migrate 等）管理；种子数据至少包含四元素 + 示例双鱼差分 + 1～2 个 MBTI。
