# 01 — 项目概述与范围

## 一句话

让 AI Pet 拥有**可版本迭代的星座×MBTI 人设**与**可审计记忆资产**，并通过 API/MCP 供给自建小智与管理台。

## 目标（Must → V0.2）

- [ ] 用户登录与设备绑定  
- [ ] `zodiac_kb` / `mbti_kb` + PersonaCompiler  
- [ ] 星座+MBTI 双选（或问卷）写入 `persona_profiles`  
- [ ] 脱敏历史存储与分页查询  
- [ ] 记忆 CRUD + Memory MCP  
- [ ] 日摘要 / 记忆候选异步任务  
- [ ] 内网接口供 `xiaozhi-server` 拉 pack、写事件  

## 非目标

- 实时 MQTT/UDP 音频  
- 重历算星盘引擎（先短日运上下文）  
- 大 IP / NFC / 社交  
- 消费级 App Feed  

## 产品规则摘录（必须遵守）

- R1/R10：Agent 只产候选，不直接改 published KB  
- R2：默认不存原始音频  
- R3：agent 记忆默认待审  
- R7：删除权可执行  
- 元素继承：双鱼 = water + pisces 差分
